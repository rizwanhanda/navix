System Architecture Overview

Client-Side Motion Engine (PDR & SLAM)

50Hz IMU sampling with 4th-order Butterworth gait filtering, dynamic Weinberg stride scaling, and a 400-particle Monte Carlo filter with hard binary wall masking.

Kotlin / Swift Particle Filter ARCore / ARKit

3-Tier Cloud & Storage Architecture

Decoupled architecture using GitHub Pages static frontend, PythonAnywhere Flask WSGI compute, SQLite3 metadata store, and Backblaze B2 S3 bucket storage.

Flask WSGI Backblaze B2 (S3) SQLite3
